Create your own locked message

  • Where the message lives: inside the link itself, after the # sign. Browsers never send that part to a server.
  • How it is locked: AES-256-GCM, with a key made from your password using PBKDF2 (600,000 rounds).
  • Limits: anyone with the link can try to guess the password, so use a long one. A link cannot expire or be taken back, and the message is not hidden from whoever has both the link and the password.
