Free security tools

Five small tools I use myself. Everything runs inside your browser. Nothing you type is sent or saved anywhere.

Password strength

An estimate, based on length and variety.

Start typing

Password generator

Uses your browser’s secure random generator.

Hash generator

SHA-256 and SHA-512 of any text, updated as you type.


      

      

      

    


    

      
Base64 encode and decode

      
Works with any language, including Urdu.

      
      
      

      

      
      
      

    

      
        

      
Watch an attacker work

      
A simulation of how real password guessing goes. Use an example password, not one you really use. Nothing is sent anywhere.

      
      

      

      

      

      

    

    
        

      
Has my password been leaked?

      
Checks the public Pwned Passwords database of hundreds of millions of leaked passwords. Only the first 5 characters of the password’s SHA-1 hash are sent, never the password itself.

      
      

      

      

      

      
Tip: test an old password you no longer use. To see exactly what is sent, open your browser’s Network tab (F12) and press Check.

    


    

      
JWT decoder

      
Reads the contents of a token. It does not check the signature, so never treat a decoded token as proof of who someone is.
